# Parked: Platform Canon Track

> This repo's planning canon is **paused**, not retracted.

## What Happened

This repo (formerly named `prix-guesser`, renamed to `paddock` on 2026-04-25) holds the long-arc platform vision for a multi-game F1 / motorsport party platform. The vision is documented in `.planning/PROJECT.md`, `.planning/LONG-ARC.md`, `.planning/ROADMAP.md`, and the supporting research / audits / phases.

That vision was framed as **Milestone 1 = a private, watchable, host-led, browser-first F1 game-night ritual for trusted groups**, with strict deferrals on:

- public live participation
- paid guaranteed access
- broad public discovery
- open creator marketplace
- adjacent non-anchor F1 modes before the anchor loop is proven
- full peer-to-peer room authority as the main branch

`.planning/LONG-ARC.md` named the conditions that would reopen the doctrine. One of them — *"the project deliberately chooses a visibility state beyond trusted private or unlisted sharing"* — was triggered when the project pivoted toward shipping public, viral, monetizable independent games that could later integrate into a platform.

Rather than rewrite the canon under uncertainty, the prototype track was spun out into its own repo so it could move fast against a different obligation profile (free, public, mobile-first, viral, server-authoritative, monetized via tip-jar + paid content packs + paid LAN host download).

## Conditions To Resume This Repo

Treat this canon as parked context until any of:

- The prototype validates and a second game enters development → portfolio architecture decisions become real, and this repo becomes the integration layer.
- The prototype invalidates and the long-arc product hypothesis itself needs revisiting → this repo's canon may be revised with new evidence.
- Operational reality changes (e.g., F1 IP enforcement against the prototype) → forces reconsideration of the long-arc plan.
- A wrapper that this canon protected (live private rooms, spectator shells) becomes the next-best step from the prototype → resume this repo's seam-preservation thinking.

Until one of those triggers fires, this repo is reference material, not active planning surface.
