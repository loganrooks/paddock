## Gap Taxonomy

- [d:r:i] The doc defects break into different remediation classes. Calling all of them "stale docs" would hide the difference between missing shipped surfaces, merely old summaries, and outright wrong defaults. Sources: `.planning/audits/2026-04-17-gsd-upstream-docs-readiness-comparative-audit/lane-01b-docs-gap-map-task-spec.md:56-60`; `.planning/audits/2026-04-17-gsd-upstream-docs-readiness-comparative-audit/lane-01-upstream-docs-freshness.md:38-45,51-59,84-94`.

| Gap type | Meaning here | Current examples | Supplementation consequence |
| --- | --- | --- | --- |
| Shipped inventory omission | A live command, feature, or agent exists on disk but is absent from the summary docs set | `gsd-graphify`; `gsd-pattern-mapper`; `gsd-debug-session-manager` | Must be added or explicitly excluded before the docs can seed inventory work |
| Underrepresented advanced surface | A capability is documented in one deep surface but not surfaced across the broader operator/contributor docs | `agent_skills` / project skills awareness | Needs cross-links plus a "who consumes this" bridge, not a full rewrite |
| Stale summary or signature | The doc covers the surface but describes an older, smaller command or mode set | `/gsd-quick`; `/gsd-thread` summaries | Needs targeted catch-up patches in summary/reference pages |
| Misleading default or provenance mismatch | The doc states the wrong default value or wrong version provenance | `claude_md_path`; `workflow.tdd_mode` | Treat as trust bugs; correct first because readers will form wrong operational assumptions |
| Stale completeness wrapper | A nav/index page claims exhaustiveness that the corpus no longer deserves | `docs/README.md` completeness language | Either remove exhaustive language or replace with generated inventory data |
| Architecture-summary flattening | The high-level story is directionally true but hides newer subsystems or role families | `docs/ARCHITECTURE.md`; `docs/AGENTS.md`; `docs/CLI-TOOLS.md` | Needs additive delta coverage, not necessarily total rewrite |
