# 05 Remediation Packet C: Host Ecology And Promotion Thresholds

## Gap justification

This packet exists to address:

- `GCO-00`
- `GCO-07`
- `GCO-08`
- `GCO-08A`
- `GCO-08B`
- `GCO-08C`
- `GCO-09`
- `GCO-09A`

Why these belong together:

- the unresolved problem is not just host ranking
- it is host comparison, transition identity, and the empirical conditions under which one branch should be promoted or deferred

This packet is not trying to close:

- browser P2P as a main branch
- generic infrastructure scaling
- a final paid hosting business model

## Purpose

Reopen the hosting transition with direct comparative grounding and determine:

- which branches are genuinely comparable
- which solve different transition problems
- what standards and trigger conditions separate trusted operators, sanctioned mirrors/collectives, and official hosted convenience

## Focus

- trusted technical supporters running the canonical authoritative bundle
- sanctioned mirrors / small host collectives
- official hosted convenience
- operator burden and standards
- host identity and labeling
- shutdown / succession / backup / compatibility discipline
