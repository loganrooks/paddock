# Round 2A Lane Common Scaffold

This is an authoring scaffold for Round 2A lane specs.

It is not the final prompt to any agent.

## Shared purpose

Each Round 2A lane should help map one part of the lived Prix Guesser experience space.

The goal is not to rank game families directly.
The goal is to make concrete experience shapes legible enough that a later foreclosure synthesis can say what early architecture must preserve.

## Shared traceability contract

Each lane should explicitly state:

- which response cluster it directly supports
- which gaps it most helps answer
- what it is not trying to close yet

Default contract:

- directly supports `RESP-03`
- contributes evidence toward `RESP-04`
- does not itself close `RESP-04`

Each lane output should also end with a short coverage note:

- `answered strongly`
- `answered partially`
- `still unresolved`

## Shared anti-goals

Do not:

- collapse everything back into mode-family ranking
- solve the final architecture-foreclosure question inside one lane
- assume every game should support every context
- treat the lane's experience class as the universal center of the product
- turn creator examples into mandatory branches unless clearly directed

## Shared methodological carry-forward

Each lane should preserve these corrections:

- ideas are design terrain, not prematurely fixed pitches
- not every game wants the same ontology
- cultural charge and mechanical spine may both be load-bearing
- absurd and still F1-rooted realizations are valid
- examples can be probes rather than taxonomies
- path, dependency, and traceability matter

## Shared stale-inheritance rule

Treat these as background-only for Round 2A:

- `01-round-1/round-1-self-eval.md`
- `03-next-round/round-2-prompts.md`

They may still be useful as historical artifacts, but they are not governing steering sources for Round 2A.

## Shared required sections

1. `Lane framing`
2. `Traceability and scope`
3. `Calibration carry-forward`
4. `What this experience feels like in practice`
5. `What kinds of game territories fit or resist it`
6. `What this experience wants from topology, authority, visibility, and cadence`
7. `What this experience does to privacy, recurrence, and community`
8. `What this lane changes about existing game judgments`
9. `What remains uncertain`
10. `What to carry into foreclosure synthesis`
11. `Coverage note`

## Shared quality bar

Good Round 2A lane work should:

- describe lived experience, not just feature buckets
- distinguish what is central from what is merely plausible
- surface tensions and tradeoffs, not just positives
- preserve room for later synthesis rather than forcing premature closure
