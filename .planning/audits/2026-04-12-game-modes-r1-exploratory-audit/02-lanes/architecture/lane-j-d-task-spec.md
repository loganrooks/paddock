# Lane J-D Task Spec

## Focus

This is a source-hunt lane.

Its job is not to settle architecture questions directly. Its job is to find promising engineering-exposure sources that could support later deeper research, including:

- talks
- GDC/conference sessions
- books
- papers
- engine/networking resources
- archived blog posts
- technical docs
- partially inaccessible but clearly relevant sources

## Questions

- What promising sources exist for the ecosystems or problems relevant here?
- Which are directly accessible?
- Which are only partially accessible but worth logging?
- What specific problem does each source appear to address?
- Why does it look relevant to Prix Guesser's possible futures?
- How trustworthy does it appear?
