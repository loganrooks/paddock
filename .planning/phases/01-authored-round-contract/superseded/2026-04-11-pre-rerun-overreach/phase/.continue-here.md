### Q2: Experience walkthroughs at each stage

**Stage 1: v1 local party (same WiFi)**
- Friday night at Logan's place. Friends arrive. Logan opens laptop, runs `pnpm dev` or maybe `./party-up.sh`. Laptop connects to TV via HDMI. TV shows a fullscreen host screen with a QR code and a 4-letter room code.

- Sessions work but there's latency on the remote friend's reveals. Not bad. Playable.

Key: Tailscale is the MVP online mode. One-time setup for remote friends. No public internet exposure yet.

**Stage 3: v2 hosted with Cloudflare Tunnel**

- Friends (any friend, no install) open the URL. Join flow identical.
- Logan runs `./party-down.sh` when done. Cloudflared tunnel stays up but the room server is idle until next `party-up`.

Key: Zero-install for guests. Still private (short-lived rooms, no persistent discoverability). Logan still hosts manually.

**Stage 4: v2.5 with async challenges**

- User wanted this specifically: "how to enable online play and not just local multiplayer, with leaderboards etc."

  - **Grid Lights** (sound/telemetry identification)
  - **Form Guide** (qualifying order prediction for historical races)

- This is the Jackbox pattern. User explicitly raised it.

**Stage 6: v3+ streamer-friendly**

  - Reduces chrome, increases contrast
  - Adds an overlay-safe area for webcam picture-in-picture

- Optional Twitch chat integration: viewers can submit guesses that appear on screen alongside friend answers
- A "spectator view" URL that shows the game without revealing answers early
