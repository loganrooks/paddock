## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authored YAML -> parser and compiler | Untrusted file content and references enter the canonical compile pipeline here |
| local asset/reference paths -> filesystem access | Relative paths can attempt traversal or silently point outside the content root |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | T | `packages/content-tools/src/loadYaml.ts` | mitigate | Parse YAML with `strict: true` and `uniqueKeys: true` and stop on parser errors. |
| T-04-02 | T | `packages/content-tools/src/pathPolicy.ts` | mitigate | Reject absolute paths and `..` traversal before opening referenced files. |
| T-04-03 | T | `packages/content-tools/src/compilePack.ts` | mitigate | Fail compilation on broken refs, alias collisions, unsafe paths, or missing fallback declarations using stable codes. |
| T-04-04 | D | `packages/content-tools/src/cli.ts` | mitigate | Keep validate/compile as explicit exit-on-error commands so failures block later phases. |
</threat_model>
