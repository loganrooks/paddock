# Prix Guesser Discovery

This directory is the pre-GSD exploration package for the project.

It exists to:
- capture the product vision without forcing a build plan yet
- map the option space before narrowing
- collect research and references
- record constraints and open questions that should shape a future `.planning/` initialization

Current framing:
- unofficial fan product
- initial audience: long-time F1 fans with strong recent-era knowledge
- core seed idea: a GeoGuessr-like game centered on grand prix locations, with room to expand into a broader F1-flavored party game

Document set:
- `01-vision.md` — current product framing and design intent
- `02-option-space.md` — plausible product directions and tradeoffs
- `03-reference-designs.md` — comparable products and patterns worth studying
- `04-modes.md` — core and adjacent game mode families
- `05-content-and-rights.md` — source opportunities and rights constraints
- `06-open-questions.md` — unresolved questions for later convergence
- `07-sources.md` — source log for claims and references
- `08-open-source-comparables.md` — GitHub repos and OSS frameworks worth studying
- `09-feasibility.md` — what looks easy, medium, and hard to prototype
- `10-critical-inheritance-geoguessr-core.md` — what to inherit, reject, and redesign for the core mode
- `11-circuit-coverage-audit.md` — venue-by-venue Street View and fallback-media viability for the core mode
- `12-framework-decision-context.md` — stack selection criteria and decision framing without locking a winner
- `13-room-backend-decision-context.md` — realtime room architecture criteria and backend decision framing without locking a winner

Status:
- exploratory
- non-binding
- intended to seed a future GSD initialization, not replace it
